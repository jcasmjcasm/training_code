# Project Budget Planner

A browser-based tool for estimating project resource costs
and planning project phases.

## Features

- Define multiple job positions
- Specify number of resources per position
- Define monthly salary per resource
- Calculate monthly and total project cost
- Define project duration
- Create project phases
- Assign resources to phases
- Visualize the project timeline

## Running locally

Download the repository and open:

index.html

in any modern web browser.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript

No external libraries or installation are required.
